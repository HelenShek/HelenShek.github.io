**简介：** 针对现有 SQL 注入检测研究大多只分析 HTTP 请求中的 Payload，而忽略了服务器响应中包含的大量信息的问题，本文提出了一种基于多智能体蜜罐系统的请求-响应上下文 SQL 注入数据集构建框架，构建了一个包含 14 万条数据的请求-响应上下文数据集，有效填补相关领域的数据短板，显著提升了主流模型在 SQL 注入检测任务上的性能表现。

**作者：** Hao Yu, Hui Li, **FengYuan Shi**, Wenjie Yu, PinHan Ho, Zehua Wang, and Bin Wang
